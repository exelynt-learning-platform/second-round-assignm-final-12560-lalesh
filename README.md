# AI Chatbox Application

A modern chatbox application integrated with OpenAI's ChatGPT API, built with React and Redux.

## Features

- 🤖 Real-time AI conversations using OpenAI GPT-3.5 Turbo
- 💬 User and AI messages with distinct styling
- ⚡ Loading states and error handling
- 📱 Fully responsive design for mobile and desktop
- 🎨 Modern and intuitive UI
- 🔒 Secure API key management
- 🧪 Unit tests for Redux actions and reducers

## Prerequisites

- Node.js (v14 or higher)
- npm or yarn
- OpenAI API key

## Installation

1. Clone the repository:
```bash
git clone <repository-url>
cd chatbox-app
```

2. Install dependencies:
```bash
npm install
```

3. Create a `.env` file and add your API key.

4. Start the app:
```bash
npm start
```
