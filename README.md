# 🤖 AI Chatbox Application

A modern **AI-powered chat application** built using **React, Redux, and OpenAI API**.
This app allows users to interact with an AI assistant in real-time with a clean and responsive UI.

---

## 🚀 Features

* 💬 Real-time AI chat interaction
* 🤖 Powered by OpenAI API
* ⚡ Redux for state management
* 🎨 Modern UI with responsive design
* 🔄 Loading indicators and error handling
* 😀 Emoji support
* 🧪 Unit tests for reducers and actions

---

## 🛠️ Tech Stack

* **Frontend:** React.js
* **State Management:** Redux + Redux Thunk
* **API:** OpenAI API
* **Styling:** CSS Modules
* **Testing:** Jest + React Testing Library

## ⚙️ Installation

### 1️⃣ Clone the repository

```bash
git clone https://github.com/exelynt-learning-platform/second-round-assignm-final-12560-lalesh.git
cd chatbox-app
```

---

### 2️⃣ Install dependencies

```bash
npm install
```

---

### 3️⃣ Setup environment variables

Create a `.env` file in root:

```env
REACT_APP_OPENAI_API_KEY=your_api_key_here
REACT_APP_API_URL=https://api.openai.com/v1/responses
```

---

### 4️⃣ Run the app

```bash
npm start
```

App will run at:

```
http://localhost:3000
```

---

## 🔐 Important Notes

* ❗ Never commit your `.env` file
* 🔑 Keep your API key secure
* 💳 OpenAI billing must be enabled
